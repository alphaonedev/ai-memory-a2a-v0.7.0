v0.7.0 expanded scope: Wave 1-4 postgres+AGE first-class

The v0.7.0 cert window surfaced an opportunity: the postgres+AGE substrate had reached SAL contract parity (20/20 PASS) but the v0.7.0-alpha framing still deferred daemon-level adapter selection to v0.7.1. Operator decision 2026-05-09 — land it in v0.7.0 rather than carve out a v0.7.0.1 / v0.7.1 micro-release. Four waves close the gap; F6 (#646) stays open until Wave 1 commits land. Tag-cut requires Wave 4 live-on-postgres re-cert. Full plan: release notes, adapter-selection runbook.

Wave 1IN FLIGHT

Surgical postgres+AGE fixes — 3 parallel streams. Stream A: PostgresStore::link() + ::register_agent(), recall 6-factor parity (tests/recall_scoring_parity.rs), migrate.rs link-walk, SQL view aliases. Stream B: new ai-memory schema-init CLI verb. Stream C: AGE 1.5 + PG 16 cypher-binding harness fix (tests/age_cte_equivalence.rs — production code never hit it). Closes F6 (#646).

Wave 2PENDING WAVE 1

Pinned by tests/postgres_schema_parity.rs.

Wave 3PENDING WAVE 2

Trait extensions recall_hybrid / sync_push_batch / sync_since already shipped via Wave 1 Stream A. --features sal-postgres opt-in; default sqlite build is byte-for-byte unchanged.

Wave 4PENDING WAVE 3

S70-S76 flip from "PASS via Path B in-tree validators" to "PASS via live daemon-on-postgres." This is the cert acceptance gate — two consecutive 100% GREEN rounds against the postgres-backed binary.
