## Documented v0.7.0.x deferrals

* **G5 final** — `find_paths` Cypher AGE 1.5 `|`-syntax limit (S65). Functional via SAL trait; HTTP surface unblocks on AGE 1.5→1.6 upgrade or explicit unroll.
* **NHI-D-quota-postgres-501** — `GET /api/v1/quota_status` returns 501 on postgres. Sqlite path works; postgres adapter incomplete.
* **NHI-D-PRIO-CLAMP** — `write_memory` silently clamps invalid `priority=0` to 5 instead of returning 400/422.
* **NHI-D-postgres-search-501** — `POST /api/v1/search` returns 501 on postgres. Hermes-observer NHI surfaced.
* **S75** — pg-DB-name + sqlite-path scenario hardcoded for Wave 4 deploy convention; repoint via runtime POSTGRES_DB env.

## Topology timeline

The cert was originally planned as a 4× GPU openclaw quad with autonomous-tier features. **DigitalOcean denied GPU droplet access on the operator account** mid-campaign (every GPU SKU returned 422 "Size is not available in this region" across every region tested). Pivoted to **Plan B**: 3× CPU droplets running `tier=semantic` against the same postgres+AGE backend, with HTTPS+mTLS preserved. Cert closes on the postgres SAL contract; autonomous-tier features (auto_tag, consolidate-via-LLM, expand_query LLM mode, detect_contradiction, smart_load) ship documented as semantic-tier-validated; live autonomous-tier cert is queued behind GPU access (v0.7.1).
